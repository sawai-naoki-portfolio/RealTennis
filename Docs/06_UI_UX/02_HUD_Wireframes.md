## 1. PC（ゲームパッド・キーボード）の HUD

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ┌────────────────────────────┐                                    [25] ⏱   │ ← ショットクロック（ポイント間のみ）
│ │● A. ARVID      6  4  30   │ ← スコアボード（左上、高さ 9%）                │
│ │  K. MORENO     4  2  15   │   ● = サーバー。セット・ゲーム・ポイント       │
│ └────────────────────────────┘                                              │
│                                                                              │
│                          （相手のコート）                                    │
│                               ◎ ← 狙いのマーカー（アシストによる）          │
│                     ─────────────────────────── ネット                       │
│                                                                              │
│                          （自分のコート）                                    │
│                               ○ ← 相手の打球の着地点（スタンダードで短く）  │
│                          🎾                                                   │
│                        [選手]  ◔ ← 溜めのゲージ（ラケットの横、小さく）      │
│                                                                              │
│                                                  PERFECT  ← タイミングの判定 │
│ 187 km/h  1,240 rpm ← 球速と回転（サーブ・ウィナーの直後、右下）            │
└──────────────────────────────────────────────────────────────────────────────┘
```

| 要素 | 位置 | 表示の条件 | 内容 |
|---|---|---|---|
| スコアボード | 左上 | 常に | 選手名（略称）、セットごとのゲーム、現在のポイント（Love/15/30/40/AD）、サーバーの印。タイブレークでは点数 |
| ショットクロック | 右上 | ポイント間 | 25 → 0。残り 5 秒で色と形を変える |
| 狙いのマーカー | 相手のコート上 | ボタンを押している間（アシストによる） | 同心円。安全マージンの内側にあるときは実線、ライン際は点線 |
| 着地点のマーカー | 自分のコート上 | アシスト（シミュレーションでは出さない） | 相手の打球の最初の着地点。打球から 0.3 秒だけ |
| 溜めのゲージ | 選手の横 | 予約中 | 円弧。満タンで縁が光る |
| タイミングの判定 | 画面の右下寄り | インパクト（スタンダード以下） | PERFECT／GOOD／EARLY／LATE。0.6 秒 |
| 球速・回転 | 右下 | サーブ・ウィナーの後 | km/h（または mph）、rpm（設定でオフ） |
| 局面の表示 | スコアボードの下 | ブレークポイントなど | 「BREAK POINT」「SET POINT」「MATCH POINT」 |
| 「2nd」 | スコアボードの右 | 第 2 サーブ | — |

## 2. サーブの HUD

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [スコアボード]                                                    2nd        │
│                                                                              │
│                ┌──────────────┬──────────────┐                               │
│                │              │      ◎       │ ← 狙い（サービスボックス内）  │
│                │              │   ワイド ←→ T│                               │
│                └──────────────┴──────────────┘                               │
│                     ─────────────────────────── ネット                       │
│                                                                              │
│                                                                              │
│                           [サーバー]   ┃▔▔▔┃ ← サーブのメーター（縦長）     │
│                                        ┃ ▬ ┃    トスの高さ（▬）と理想の打点 │
│                                        ┃███┃    （帯）、溜め（塗り）       │
│                                        ┗━━━┛                               │
└──────────────────────────────────────────────────────────────────────────────┘
```

| 要素 | 内容 |
|---|---|
| サーブのメーター | 縦長。トスのボールの現在の高さ（横線）が上下する。理想の打点の帯（Perfect の範囲）を色で示す。溜めは下から塗る |
| 狙い | サービスボックスの中だけを動く。ワイド・ボディ・T の位置に小さな目盛り |
| トスのやり直し | トスが横に 0.1 m 以上ぶれたら、「LB：やり直し」の案内を出す（スタンダード以下） |
| シミュレーション | メーターを出さない（トスの見た目と音だけで打つ） |

## 3. タッチ（スマートフォン）の HUD

### 3.1 ボタン方式

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [Ⅱ] [スコアボード（小）]                                        [📷]        │
│                                                                              │
│                          （コート：中継カメラ）                              │
│                                                                              │
│                                                                              │
│                                                          (Y)                 │
│     ╭─────╮                                         (X)       (B)            │
│     │  ●  │  ← 浮動スティック                            (A)                 │
│     ╰─────╯     （左半分のどこでも）              [強打]       [技]          │
└──────────────────────────────────────────────────────────────────────────────┘
```

| 要素 | 寸法（画面の高さ比） | 規則 |
|---|---|---|
| 球種のボタン | 直径 13%（最小 48 dp） | 右下、円弧に並べる。ラベルは球種の絵（トップスピン＝上向きの弧など） |
| 強打・技 | 直径 9% | 球種のボタンの左下 |
| 浮動スティック | 半径 12 mm 相当 | 触れた点が中心。離すと消える |
| ポーズ・カメラ | 7% | 上の端（セーフエリアの内側） |
| 透明度 | 既定 60%、触れている間 90% | 設定で変更 |

### 3.2 スワイプ方式

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [Ⅱ] [スコアボード（小）]                                        [📷]        │
│                                                                              │
│                          （コート：中継カメラ）                              │
│                                   │                                          │
│              左半分：移動の修正     │     右半分：スワイプで打つ             │
│              （浮動スティック）     │       ↑ まっすぐ＝フラット            │
│                                   │       ⤴ 上に反る＝トップスピン          │
│                                   │       ⤵ 下に流れる＝スライス          │
│                                   │       ⇈ 長く上へ＝ロブ                  │
│                                   │                          [技]           │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 初めて使うときに、形の練習（チュートリアル）を表示する
- スワイプの軌跡を指の後ろに薄く描き、判別した球種の絵を 0.4 秒表示する
- 判別の信頼度が低いときは、絵の横に「？」を付ける（既定の球種で打ったことを示す）

## 4. ミスの理由の表示

```
            ┌────────────────────────────┐
            │  OUT  ── 振り遅れ           │   ← ポイント後、画面の中央下に 1.5 秒
            │          （タイミング +0.11 s）│      シミュレーション：理由だけ
            └────────────────────────────┘      スタンダード以下：数値も
```

| 原因（`EMissCause`） | 表示 |
|---|---|
| Timing | 「振り遅れ」／「早すぎ」（＋ Δt） |
| Contact | 「打点がずれた」 |
| Height | 「打点が低い」／「打点が高い」 |
| Posture | 「体勢が崩れた」 |
| Pace | 「球威に押された」 |
| Risk | 「狙いすぎ」（＋ ラインまでの距離） |
| Pressure | 「プレッシャー」 |
| Solver | 「無理な体勢から打った」 |

## 6. 色と形（アクセシビリティ）

| 情報 | 色 | 形（色以外の区別） |
|---|---|---|
| イン | 緑系 | 実線の円 |
| アウト | 赤系 | 破線の円と × |
| 狙い（安全） | 白 | 実線の同心円 |
| 狙い（ライン際） | 黄系 | 点線の同心円 |
| PERFECT／GOOD／EARLY・LATE | 金／白／灰 | 文字そのもの |

- 色覚のパレット（標準／1 型／2 型／3 型）で色だけを差し替える（NFR-ACC-002）
- 文字の大きさは 3 段階（標準・大・特大）。スコアボードも連動する
