# DD-08：サウンド 詳細設計

| 項目 | 内容 |
|---|---|
| 文書 ID | DD-08 |
| 版 | 1.0（2026-11-04） |
| 対象のクラス | `UTennisAudioDirector`、`UTennisCrowdComponent`、`UTennisUmpireComponent`、MetaSounds のアセット（`MS_*`）、Sound Modulation |
| 要件 | FR-SND-001〜006、FR-PRES-004・006、NFR-ACC-003・007 |

---

## 1. 構成

```
UTennisEventSubsystem ──▶ UTennisAudioDirector ──▶ MetaSound の音源（パラメータを渡す）
                                   │
                                   └─▶ Sound Modulation（コントロールバス）：観客のダッキング、ミックスの状態
```

| サブミックス | 内容 | 既定の音量 |
|---|---|---|
| `SM_Gameplay` | 打球・バウンド・ネット・足音・選手の声 | 0 dB |
| `SM_Crowd` | 観客 | −3 dB |
| `SM_Voice` | 主審・電子ラインコール | 0 dB |
| `SM_UI` | メニューの効果音 | −6 dB |
| `SM_Music` | メニューの音楽（試合中は流さない） | −8 dB |

## 2. 打球音（`MS_Hit`）

| パラメータ | 入力 | 音への効果 |
|---|---|---|
| `Speed`（m/s） | 打ち出しの速さ | 音量 +0.3 dB/(m/s)、ピッチ +0.6 半音/(10 m/s) |
| `Quality`（0〜1） | 品質 | アタックの鋭さ、高域の明るさ。Perfect で「澄んだ」層を加える |
| `ShotFamily` | 球種 | スライス・ドロップは低域を強め、こもった音。フラットは高域 |
| `OffCenter`（m） | スイートスポットからの距離 | 0.08 m を超えると「フレームに当たった」金属的な層を混ぜる |
| `Surface` | なし | — |

**層**：ガットの「ポン」（主）、ボールの打撃（低域）、フレームの響き（OffCenter で）、空気を切る音（スイングの速さ）。各層に 4〜6 個の変種を用意し、ランダムに選ぶ（演出なので `FMath::Rand` でよい）。

## 3. バウンド・ネット・ポスト

| 音 | パラメータ | 変種 |
|---|---|---|
| `MS_Bounce` | 面（クレー・ハード・芝・室内）、v_n、滑りの速さ | 面ごとに 6 個 |
| `MS_Net` | 部位（本体・白帯）、強さ | 本体 4、白帯 4 |
| `MS_Post` | 強さ | 3 |
| `MS_Fixture` | 種類（フェンス・看板・壁） | 各 3 |

## 4. 選手

| 音 | 条件 |
|---|---|
| 足音 | 面ごと。移動の速さで間隔と強さ |
| シューズの鳴き | ハードと室内で、減速 > 6 m/s² のとき（0.3 s に 1 回まで） |
| スライド | クレーのスライド（長さに合わせて伸ばす） |
| 声（うなり） | 打ち出しの速さが 32 m/s を超える、またはサーブ。選手ごとの声の組（12 種類の声質）。音量は速さで |
| 息 | スタミナが 30% を切ったとき、ポイントの間 |

## 5. 観客

| 層 | 内容 | 制御 |
|---|---|---|
| ざわめき（Bed） | 常に流れる。会場の大きさで残響 | 盛り上がり（Excitement）で音量 |
| 期待（Anticipation） | ラリーが長くなるにつれて「おお」と高まる | ラリーの長さ |
| 拍手 | ポイントの後 | 強さ（[DD-07 §5](07_Camera_Presentation_Detail.md)） |
| 歓声 | ウィナー・エース・重要な局面 | ポイントの価値 |
| ため息 | ダブルフォルト・凡ミス・ネット | — |
| 静寂 | サーブの準備でダッキング（−18 dB、0.8 s で） | Modulation の `CB_CrowdDuck` |

## 6. 主審・電子ラインコール

- コールの一覧は [DD-04 §5](04_Rules_Match_Detail.md)
- 収録：英語。主審 2 人（男女）× 全コール。選手の名前 24 人分
- 字幕：UI の言語で表示（NFR-L10N-002）。音声だけの情報を作らない（NFR-ACC-007）
- 電子ラインコールの声は、主審とは別の声（"Out"・"Fault"・"Foot fault"）
- 再生の遅れ：判定から 0.3 s 以内に始める（FR-PRES-004）

## 7. ミックスの状態

| 状態 | 内容 |
|---|---|
| `Rally` | 打球音を優先。観客 −3 dB |
| `ServeReady` | 観客 −18 dB（静寂）。足音とボールをつく音を強調 |
| `PointEnd` | 観客 +3 dB、打球音のテール |
| `Replay` | 打球音を 0.5 倍速に合わせたピッチ（ピッチは下げない設定も可）、観客は控えめ |
| `Menu` | 音楽を流す |

## 8. 音量と品質

| 項目 | 値 |
|---|---|
| ラウドネスの目標 | 試合中 −16 LUFS（積分）。モバイルのスピーカー向けに、ダイナミクスを少し圧縮するプリセット |
| 同時発音 | 打球 4、バウンド 4、観客の層 6、声 2 |
| 距離減衰 | コートの音は、カメラからの距離ではなく「中継のマイク」の位置（コートの中心）で計算する（どのカメラでも一定に聞こえる） |
| 設定 | 全体・効果音・観客・音声・音楽の 5 つ（FR-SND-006） |
