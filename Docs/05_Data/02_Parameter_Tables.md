入力バッファは `UTennisInputSettings` の `InputBufferSeconds`（Config/DefaultGame.ini。アシストの段階で値を分けるのは W-4.3）。ストロークごとの ReleaseLeadTime と ChargeTime は [操作仕様 §4.1](../01_Specification/04_Controls_Specification.md)。

サーブの理想打点は地面から選手の身長 × 1.52、トスの目標頂点はそこから +0.05 m。前者は [DD-03 §10](../04_DetailedDesign/03_Player_Movement_Stroke_Detail.md) の設計値、後者は [SPEC-04 §5](../01_Specification/04_Controls_Specification.md) の操作感の調整値。下降時の打点を対象とし、頂点付近の品質を FR-STRK-010／T-STRK-006 で検証する。

サーブ品質（W-3.7、FR-STRK-010、T-STRK-006）の調整初期値。実際の打点で評価する。頂点からの高さの差の絶対値を `d`（m）、意図したトス位置からの横ずれの絶対値を `y`（m）とする。

- 高さの減点は `max(0, d − 0.05) × 1.0`。理想打点から頂点までは満点、頂点から 0.15 m で品質 0.90 を満たす直線を、その先にも連続して延ばす。
- 横の減点は `1.5 × y`（SPEC-04 §5）。品質は `clamp(1 − 高さの減点 − 横の減点, 0, 1)`。タイミング評価は同じ高さの誤差への追加の減点に使わない。
- 球速を決める溜めは、操作の溜めに第 2 サーブの上限を適用した値と品質の積。球種の最低速と最高速の間をこの値で補間する。
- 横ずれなしで高さの差 0・0.05・0.15 m、更に低い打点へ連続的に下げたときの単調性、横ずれ 0.10 m の単独減点、品質の下限、溜めと品質の組合せを検証する。
