| 項目 | 内容 |
|---|---|
| 対応内容 | Blender のスクリプト（`Tools/Blender/build_players.py`）で作った仮の選手 `SKM_Player_Male01`・`SKM_Player_Female01` を、既存の骨格 `SK_TennisPlayer_Base` に取り込み、既定の選手（Project Settings の Tennis Player の `Mesh`）を男性にする |
| ブランチ | `art/interim-players` |
| 撮影 | Blender の画像は Blender MCP の `look`（マテリアルの表示）。ウィンドウの枠と `.blend` のパスは写らない。PIE の画像は `Tools/Screenshots/Capture-Window.ps1` でテストマップ `L_TestCourt` を撮り、拡大は選手の周りを切り出して 4 倍にした。女性の PIE は、`Mesh` を一時的に女性へ替えて撮った（コミットした既定は男性）。色は確認用の仮の色 |
