# 2026-11-11 仮の選手（Manny・Quinn）を取り込み、骨格にラケットのソケットを足す（A-CHR-001〜003）

| 項目 | 内容 |
|---|---|
| 対応内容 | エンジンのテンプレートの UE5 Mannequin から、骨格・Manny・Quinn・マテリアル・テクスチャ・物理アセット・仮のロコモーションを取り込み、`Content/Tennis/Characters/` へ移す。骨格の名前を `SK_TennisPlayer_Base` にし、ラケットを持つソケット `racket_attach_r`・`racket_attach_l` を足す（[ART-01 §3.1](../../../07_Art_Animation/01_Asset_List.md)） |
| ブランチ | `art/player-mannequin` |
| 撮影 | 保存しない新しいレベルに、Manny（参照姿勢）とラケットを**仮に置いて**撮った。ラケットの位置と向きは、参照姿勢の `hand_r` と `racket_attach_r` から計算して、ラケットの `grip` をソケットに重ねた（Unreal MCP にはソケットへの取り付けのツールがないため）。撮った後に消した |
