# センターコート A ｜ハードコート・客席・コートサイド備品

2026-11-21。Blender の組み立てシーンを Cycles でレンダリング。ゲーム用のメッシュを並べ、ネットの網だけは UE のマスクを細い線で表している。

| 画像 | 見るところ |
|---|---|
| スタジアム全景（画像：公開版には未収録） | 2 層の客席 14,804 席。縦通路、横通路、四隅の出入口を空けている。 |
| ハードコートと客席（画像：公開版には未収録） | ブルーのシングルス面、ダブルスのアレー、緑の余白、埋め込みライン、客席との位置関係。 |
| コートサイド備品（画像：公開版には未収録） | 手前からネット、木製スラットの選手席、タオルとボトル2本を置いたテーブル、審判台、放送カメラ。 |
| UEで開いた会場（画像：公開版には未収録） | 専用レベルに配置した2層の客席とハードコート。 |
| PIEの中継カメラ（画像：公開版には未収録） | ベースライン後方で選手が接地。透過する網越しに向こう側のコートが見える。 |

UE ではコンテンツブラウザから `/Game/Tennis/Maps/L_CenterCourtA` を開き、プレイする。床の単純衝突は両ベースライン付近とランオフの3点で地面から 0.05 cm 以内。PIE では選手が歩行状態になり、ボール1個を確認した。プレイ用の開始地点と中継カメラは既存のゲームモードを使用する。

再生成には [Blender の手順](../../../../Tools/Blender/README.md)を使う。
