# 2026-11-19 低く打つ変種 Dip の仮のストローク（W-3.5、DD-03 §5.3）

| 項目 | 内容 |
|---|---|
| 対応内容 | 同じ高さの帯の中の低い打点を、腰を落として打つ変種 `Dip`（フォア・片手バック）を足し、打点の高さで今のストロークと選び分ける（境界：フォア 0.93 m、バック 0.97 m）。PIE のログ：Dip はフォア・バックとも `impact distance=0.012`・`0.011`、今のストロークは `0.011`・`0.011` で、どれも打ち返した |
| ブランチ | `art/stroke-dip` |
| 撮影 | テストマップ `L_TestCourt` の PIE（中継カメラ。既定の選手 M01）。打球ツール（`shoot_ball`）で、低い球（トップスピン、着地 (−9.0, ±1.0) m → Dip）と高い球（ヘビートップスピン、着地 (−8.0, ±1.0) m → 今のストローク）を打ち、J（トップスピン）を短く押した。`tennis.TimeScale` を下げて、`Tools/Screenshots/Capture-Window.ps1` で続けて撮った（撮った後に 1 に戻した）。選手のまわりを切り出して拡大した |
