# 2026-11-14 打点の候補でストロークを振る（W-3.5、DD-03 §6.6）

| 項目 | 内容 |
|---|---|
| 対応内容 | 球種のボタンを押して打点の候補が見つかると、選手が `UTennisStrokeComponent` でストロークを振る。ボールのステップの通し番号で進め、止めたモンタージュの位置と体の向きを合わせる。インパクトの時刻はボールの時刻の上で打点の時刻と合い（ログ `impact t=21.77083 hit=21.77083`）、RecoverStart で終わって入力が待機に戻る（ログ `stroke ended -> Idle`）。インパクトの判定と打球はまだない（ボールは選手の横を通り過ぎる） |
| ブランチ | `feat/stroke-wiring` |
| 撮影 | テストマップ `L_TestCourt` の PIE（中継カメラ）。`tennis.TimeScale` を 0.25 にして（撮った後に 1 に戻した）、打球ツール（`shoot_ball`、トップスピン、着地 (−9.0, 1.0) m）で打ち、すぐに J（トップスピン）を押し続けて、`Tools/Screenshots/Capture-Window.ps1` で続けて撮った。選ばれたのは仮のフォア `DA_Stroke_FH_Mid_Drive_Square` |
