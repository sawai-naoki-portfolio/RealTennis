## 1. コンセプト

### 1.1 ひとことで

> **「本物の物理で飛ぶボールを、自分の足と読みとタイミングで打ち返す、1 対 1 のテニス・シミュレーション」**

### 1.2 体験のゴール

| # | プレイヤーが感じること | それを作るもの |
|---|---|---|
| 1 | 「いい当たりだった」と手で分かる | タイミングの窓、インパクトの瞬間の音と振動、打点の品質 |
| 2 | 「足で追いついた」「読みが当たった」 | 人間らしい加速、スプリットステップ、相手の打点からの予測 |
| 3 | 「このコートはボールが跳ねる／滑る」 | 物理（CPR に基づく面）、球の Type、気温・標高・風 |
| 4 | 「本物の試合をしている」 | ITF 2026 の規則、主審のコール、試合の時間の流れ、統計 |
| 5 | 「相手が人間らしい」 | AI がプレイヤーと同じ物理と誤差の仕組みで打つ。プレースタイルがある |

### 1.3 柱（Pillars）と、柱に反するもの

| 柱 | 意味 | 柱に反するもの（やらない） |
|---|---|---|
| **P1 本物の物理** | ボールは常に同じ物理で飛ぶ。難易度でも変えない | 「必殺ショット」、ボールの軌道の演出的な曲げ |
| **P2 ミスは理由がある** | ミスはタイミング・体勢・球威・リスクから生まれる。理由をプレイヤーに伝える | ランダムなミス、見えない補正 |
| **P3 本物のルールと流れ** | ITF 2026 の規則を満たす。試合の時間とテンポを再現する | 独自ルール（ただし短縮形式は ITF の代替方式の範囲で用意する） |
| **P4 足とポジション** | 正しい位置に早く入ることが最大の武器 | 自動で打点に吸い付く移動（アシストは任意で、弱めにする） |
| **P5 中継の見た目と音** | テレビ中継のようなカメラ・リプレイ・音 | ゲーム的な派手なエフェクト（Perfect の小さな演出は可） |

## 3. ゲームモード

| モード | 内容 | 版 | 優先度 |
|---|---|---|---|
| **エキシビション** | 選手・コート・試合形式・AI の難易度を選んで 1 試合。AI 対戦／同じ画面の 2 人対戦／AI 対 AI の観戦 | v1.0 | Must |
| **練習** | (1) 球出し機（球種・コース・速さ・間隔を設定）、(2) サーブ練習（的あり）、(3) ラリー練習（AI がミスしない設定）、(4) 状況練習（ブレークポイントなどの局面から開始） | v1.0 | Must |
| **トーナメント** | 8／16／32 人のトーナメント（AI）。コート面・ボール・標高・天候は大会ごとに固定 | v1.0 | Should |
| **ツアー（キャリア簡易版）** | 架空の 1 年間の大会カレンダーを回る。ランキングポイントと選手の成長 | v1.1 | Could |
| **オンライン対戦** | 1 対 1（フレンド招待と、クイックマッチ） | v1.1 | Should |
| **リプレイシアター** | 保存したポイントのリプレイを自由なカメラで見る | v1.0 | Could |

## 4. ゲームの流れ

### 4.1 1 試合の流れ

```
選手・コート・形式の選択 → 入場（スキップ可） → コイントス（サーブ／レシーブ／エンドの選択）
→ ウォームアップ（任意、最大 5 分 → 既定はスキップ）
→ [ポイント] × N
     サーブ準備 → トス → サーブ → ラリー → ポイント終了（コール） → 短いリプレイ（任意）
     → ポイント間（最大 25 秒のショットクロック。ボタンで進める）
→ エンドチェンジ（90 秒。統計の表示。ボタンでスキップ）
→ セットブレイク（120 秒）
→ 試合終了 → 統計 → リプレイのハイライト → 結果画面
```

### 4.2 1 ポイントのコアループ

```
相手のインパクト ─▶ スプリットステップ（自動。タイミングが合うと初動ブースト）
      │
      ▼
 着地点を読む（ボールの軌道・相手の体勢・スイングの向きを見る）
      │
      ▼
 移動（左スティック） ─▶ ストロークの予約（球種ボタンを押す → 溜め開始）
      │                          │
      │                          ▼
      │                  狙い（左スティックの向き。押している間）
      ▼                          │
 打点に入る（足の位置が良いほど品質が上がる） ◀─┘
      │
      ▼
 ボタンを離す（タイミング判定：Perfect／Good／Early／Late）
      │
      ▼
 インパクト → ショットの品質 → 誤差 → ソルバ → 物理で飛ぶ
      │
      ▼
 リカバリー（センターへ戻る。相手の打てる範囲の角の二等分線上）
```

### 4.3 リスクとリターン

| 選択 | リターン | リスク |
|---|---|---|
| 溜めを長くする | 球速が上がる | 振り遅れやすい。体勢が崩れていると誤差が大きい |
| ライン際を狙う | 相手を大きく動かせる | 誤差（σ）でアウトになる確率が上がる |
| フラットで打つ | 速く低い | ネットとアウトのミスが多い（回転で落ちない） |
| トップスピン | 安全に深く、高く弾む | 球速は落ちる |
| ネットに出る | 角度をつけて決めやすい | パスとロブに弱い |
| 早いタイミングで打つ（ライジング） | 相手の時間を奪う | タイミングの窓が狭い |

## 5. 選手

### 5.1 能力値（0〜100）

| カテゴリ | 能力値 | 主な効果 |
|---|---|---|
| ストローク | フォアハンド、バックハンド | 誤差 σ と最大球速の倍率 |
| ショット | サーブの球威、サーブの精度、ボレー、スマッシュ、スライス、ドロップ、ロブ | ショット種別ごとの σ・最大球速・回転の倍率 |
| 回転 | 回転量 | 最大回転数の倍率（トップスピン・キック） |
| 身体 | スピード、加速、スタミナ、リーチ | 移動のパラメータ、到達範囲（腕の長さと身長から） |
| 精神 | 安定性（大事な場面で σ が増えにくい）、予測（AI の場合は反応時間） | 局面による補正 |

- 総合値は表示用（能力値の重み付き平均）
- **利き手**（右／左）と**バックハンドの打ち方**（片手／両手）を持つ。左利きはサーブのスライスの曲がりとアドサイドでの角度が逆になる。これは物理でそのまま表現される
- 身長（170〜205 cm）でサーブの打点とリーチが変わる。体格はモデルのスケールではなく、骨格の比率のプリセットで変える

### 5.2 プレースタイル（AI の振る舞いと、能力値の初期配分）

アグレッシブ・ベースライナー、カウンターパンチャー、ビッグサーバー、サーブ＆ボレー、オールコーター、スピン・スペシャリスト（[RES-03](../00_Research/03_Player_Match_Stats_Research.md) §6）。

### 5.3 スタミナ

- 長いラリー・ダッシュ・スライド・強いサーブでスタミナを消費する。ポイント間・エンドチェンジで回復する
- スタミナが減ると、最高速度・加速・溜めの速さが少し下がり、σ が少し増える（最大で −8%、+15%）
- **ゲームの結果をスタミナだけで決めない**。5 セットマッチの後半でも、ラリーは成り立つ程度の影響にする

### 5.4 架空の選手

- 初期収録：架空の選手 24 人（男女 12 人ずつ）。国籍・スタイル・能力値・外見はばらばらにする
- **実在の選手・大会・ブランドは使わない**（肖像権・商標）。大会名・コート名も架空にする

## 6. コートと環境

| 面 | ITF の区分（目標 CPR） | 体感 | 推奨の球 |
|---|---|---|---|
| クレー（赤土） | Cat 1（26） | 高く弾み、遅い。スライドする。ボールマークが残る | Type 1 |
| ハード（中速） | Cat 3（38） | 標準 | Type 2 |
| ハード（やや速い） | Cat 4（43） | 少し速い | Type 2 |
| 芝 | Cat 5（51） | 低く滑る。ラリーが短い | Type 2 または 3 |
| 室内ハード（速い） | Cat 5（51） | 速く、無風 | Type 3 |

| 環境 | 範囲 | 効果 |
|---|---|---|
| 気温 | 5〜40 ℃ | 空気密度と球の反発（暑いと速く、よく弾む） |
| 標高 | 0〜2,500 m | 空気密度（高地はよく飛ぶ）。高地では High Altitude 球か Type 3 を推奨 |
| 風 | 0〜6 m/s（屋外のみ） | ボールが流れる。ソルバは平均風しか知らない |
| 時間帯 | 昼・夕方・ナイター | 照明と影（見た目だけ） |
| 屋根 | 開／閉 | 閉は無風 |

## 8. 難易度とアシスト

**原則：アシストは物理とルールを変えない**（[RES-05](../00_Research/05_ExistingDesign_Review.md) §4）。

| 設定 | 選択肢 | 効果 |
|---|---|---|
| AI の難易度 | Easy／Normal／Hard／Pro／Legend | 反応時間、予測の誤差、タイミングの誤差、狙いのマージン、リスク選好（[パラメータ表](../05_Data/02_Parameter_Tables.md) §5） |
| プレイヤーのアシスト | シミュレーション／スタンダード／カジュアル | 下の表 |

| 項目 | シミュレーション | スタンダード | カジュアル |
|---|---|---|---|
| タイミングの窓（Good） | ±0.07 s | ±0.09 s | ±0.13 s |
| 移動のアシスト（理想打点への引き寄せ） | 0% | 15% | 35% |
| 狙いの安全マージン | 0 m | 0.3 m | 0.8 m |
| 着地点マーカー | なし | 相手の打球の着地点を短く表示 | 常に表示 |
| タイミングのメーター | なし | 小さく表示 | 大きく表示 |
| ミスの理由の表示 | ポイント後だけ | ポイント後だけ | 毎回 |
| 自動のスプリットステップ | 手動（ボタン） | 自動 | 自動 |

## 9. 見た目・音・演出

| 項目 | 内容 |
|---|---|
| カメラ | 中継カメラ（既定）、ローカメラ、選手の後方。サーブとリターンの瞬間だけ、自動で少し寄る（設定でオフ） |
| リプレイ | ポイント後の短いリプレイ（ウィナー、エース、長いラリー、際どい判定のときだけ。スキップ可） |
| 際どい判定 | ELC 風の CG 再現（ボールの接地の跡とラインの拡大） |
| 主審 | スコアのコール（英語の音声＋字幕）。「Fault」「Let」「Out」などのコール |
| 観客 | ラリーの長さで盛り上がりが上がる。ポイント後の拍手。サーブ前は静かにする |
| 選手 | ポイント後のリアクション（ガッツポーズ、悔しがる）。タオル、ボールを要求するしぐさ（演出のみ） |
| ボールパーソン | ボールを拾う・渡す（アニメーション。v1.0 は簡易版） |

## 10. 収益化・配信（参考）

- PC：買い切り（Steam）。v1.0 の後に、無料のアップデートでダブルス・キャリアを追加する。課金要素は入れない
- スマートフォン：App Store／Google Play。買い切り、または「無料の体験版（練習とエキシビションの一部）＋アンロック」のどちらにするかは未定。ゲームの内容は PC と同じにし、課金による有利不利は作らない

## 10.1 スマートフォン版の方針

| 項目 | 方針 |
|---|---|
| 内容 | PC と同じ（物理・ルール・AI・モード）。プラットフォームで物理を変えない |
| 操作 | タッチの 2 方式（**ボタン方式**・**スワイプ方式**）。初期のアシストは「カジュアル」、移動のアシストを強めにした「タッチ向け」プリセットを用意する |
| 画面 | 横画面のみ。ノッチとホームバーのセーフエリアを避ける。タッチのボタンは画面の 1/4 以内に収め、コートを隠さない |
| 中断 | アプリがバックグラウンドに入ったら、自動でポーズする。オンラインでは切断として扱う（60 秒の猶予） |
| 振動 | iOS は Core Haptics、Android は振動 API（インパクトの品質で強さを変える） |
| 試合の長さ | 既定のプリセットを「クイック」（1 セット）にする。PC と同じ形式も選べる |
| セーブ | 端末に保存。クロスセーブ（EOS のプレイヤーデータ）は Should |

## 12. 用語集

| 用語 | 意味 |
|---|---|
| CPR | ITF のコートペースレーティング。面の速さの指標 |
| ショットソルバ | 狙った着地点から、ボールの打ち出しの速度と角度を逆算する仕組み |
| σ（シグマ） | 狙いの誤差の標準偏差（m）。小さいほど正確 |
| 品質（Quality） | タイミング・打点・体勢から計算する 0〜1 の値。σ と球速に影響する |
| スイートスポット | ラケットの打球面で、最もよく飛ぶ点。インパクトの判定の基準 |
| リカバリー | 打った後に、次の球を待つ位置へ戻る動き |
| ELC | 電子ラインコール |
| KPI | ここでは、リアルさを測る統計の目標値（ラリーの長さなど） |
