## 0. 凡例

- **ID**：`FR-<領域>-<番号>`
- **優先度**：**M** = Must（v1.0 に必須）／**S** = Should（v1.0 で入れたい）／**C** = Could（余裕があれば）／**M¹** = v1.1（スマートフォン版）で必須
- **MS**：実装するマイルストーン（M0〜M9。[ロードマップ](../09_Project/01_Roadmap_WBS.md)）
- **検証**：**AT** = 自動テスト（テスト ID）／**PT** = プレイテスト／**RV** = レビュー（目視・コード）

| 領域 | 略号 | 領域 | 略号 |
|---|---|---|---|
| コート | CRT | AI | AI |
| ボール物理 | BALL | ネットワーク | NET |
| 環境 | ENV | カメラ | CAM |
| ショット | SHOT | 演出（エフェクト・審判・観客） | PRES |
| 入力 | INP | サウンド | SND |
| 移動 | MOVE | UI | UI |
| ストローク・アニメ | STRK | モード | MODE |
| ルール | RULE | 統計・リプレイ | STAT |
| スコア | SCR | セーブ・設定 | SAVE |
| 試合進行 | MATCH | デバッグ・ツール | DBG |
